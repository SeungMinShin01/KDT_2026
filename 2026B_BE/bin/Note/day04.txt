[ 객체 ] 객체지향 프로그램
    1. 정의 : 상태(멤버변수/필드/속성) 와 행위(메소드 / 함수)를 정의하는것
    2. 클래스 : 상태와 행위를 코드로 작성(설계)
        -> 용도 : 1. 설계 2. 실행(main함수를 갖는)
    3. 인스턴스 : 특정 클래스로 생성(new)한 객체(실체)
    4. 사용법 
        1. 클래스 생성
            - class 클래스명 { 멤버변수; 생성자; 메소드; }
            - 멤버변수 : 
                타입 변수명;                *초기값이 없으면 기본값
                타입 변수명 = 초기값;
        2. 인스턴스 생성
            - new 생성자명( );              * new 1개당 인스턴스 1개 생성(즉 메모리 주소값 생성) *
            - 타입 변수명 = new 생성자명( );
        3. 인스턴스 참조
            - 객체변수명.멤버변수명;         * .(접근/도트)연산자 : 변수가 갖는 객체의 주소로 이동한다.
            * null. 불가능 null : 변수가 null이면 이동할 주소(참조할 객체)가 없다.
        * 객체는 변수가 참조하지 않으면 자동으로 사라진다(GC)
    -- src(개발자 코드 .java), bin(컴파일/번역코드 .class)
